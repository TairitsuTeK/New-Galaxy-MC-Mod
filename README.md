# Minecraft Java Edition Mod: New Galaxy 新星系（Demo）

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Minecraft](https://img.shields.io/badge/Minecraft-1.21.1-blue.svg)](https://www.minecraft.net/)
[![NeoForge](https://img.shields.io/badge/NeoForge-21.1.1+-red.svg)](https://www.neoforged.net)

**New Galaxy** 是一款基于 Minecraft Java Edition 1.21.1 与 NeoForge 的星系模组，灵感来源于 Micdoodle8 的经典模组 [Galacticraft](https://github.com/micdoodle8/Galacticraft)。

它面向较新版本的 Minecraft，主要扩展了太阳系及各大天体的维度，为玩家提供从主世界出发、探索星际的完整体验。

---

## 主要内容

### 1. 太阳系天体维度

- 为游戏添加了多个可传送前往的天体维度（使用传送器打开星图进行传送）。当前已完成 **26 个自定义天体维度**（13 颗行星/矮行星 + 13 颗卫星；主世界保持原版），另有 1 个不通过星图选择的 `newgc:space` 太空漂流维度，其余内容将在后续版本中继续扩展。
- 新增 **半人马座α星系**：星图顶部可切换“太阳系 / 半人马座α”，新增可传送的潮汐锁定行星 **比邻星b（Proxima b）**。
- 半人马座α的星图图标、Proxima b 方块贴图和方块模型已统一为太阳系规格：16×16 方块贴图、16×16 行星图标、8×8 恒星图标、关闭 GUI 纹理模糊，并共用 `cube_all` 方块模型。
- 已实现的深空天体包括：土星、天王星、海王星、冥王星、鸟神星、妊神星、阋神星，以及木卫二、木卫三、木卫四、土卫六、天卫三、天卫四、海卫一、冥卫一、妊卫一。
- 每颗星球都拥有独立的岩石体系（表层、浅层、深层三层结构）、独立的噪声密度/高度参数和专属矿物生成。本模组的矿物、锭、粒、块等物品**自成体系**，暂不与其他模组的同类物品通用，以避免配方冲突。
- 每颗星球拥有独立的重力系统（倍率经过游戏化调整，避免出现“接近原版、难以察觉”的维度），并结合了贴合现实星球的粒子效果、生物群系生成和天空渲染。例如：金星拥有独特的酸雨效果，地表遍布岩浆池与酸雨池；水星上太阳的视直径极大，天空深邃黑暗。
- 所有自定义天体都使用自主天空渲染，不会回退到原版天空：已有天体的星空/太阳渲染保留，新增的 16 个深空天体使用独立的星空 + 太阳渲染，金星则使用浓密橙黄色大气穹顶。
- **星球与卫星自然方块**：岩石、浅层、深层、矿脉和月壤恢复为项目初版的 16×16 纹理，保留最初的像素风格。
- 新增/重绘的金属、合金、机器和火箭物品纹理统一为 **32×32** 像素，细节更清晰；
  行星图标与恒星图标仍分别保持 16×16 与 8×8 的星图规格。
- 自定义维度不会渲染原版云层，因此在地下洞穴中不会再出现“云穿地”的问题；木星风暴现在会从平静期开始、平滑过渡，并在玩家进入木星时立即同步当前风暴状态。

### 2. 星图

- 太阳系轨道图。太阳位于中心，周围是其他星球按椭圆轨道布局。
- 新版采用“任务控制台”式布局：顶部为标题与操作栏，左侧为天体列表，中央为轨道图，右侧为目标信息卡；
  所有面板统一为深蓝玻璃、细冰蓝描边和低对比度渐变，不再使用亮色硬边框。
- 手持传送器即可打开星图，点击顶部右侧的“传送”按钮即可前往目标星球。
- 星图内的星球沿平滑的高分段椭圆轨道缓慢公转；未选中的轨道压暗为细线，选中/悬停轨道才稍微提亮。
- 背景保持简洁：只显示深空星尘、基础星点和偶尔划过的流星，不再绘制星云、极光、日冕或行星光晕。
- 所有自定义维度统一关闭原版日出/日落色带，避免转向某个方向时出现黄昏效果。
- 星图顶部中央新增星系切换器，可在 **太阳系** 与 **半人马座α** 之间切换；半人马座α使用双星图标和独立的 Proxima b 目标卡。
- 半人马座α目前作为深空传送路线开放（手持传送器即可前往）；一阶/二阶/三阶火箭则按所在天体的卫星链与相邻行星选择目的地。
- 打开时中央轨道图由内向外缓慢展开（约 1.5 秒），外围界面保持固定不缩放；缩放 / 平移 / 旋转都按真实时间平滑（更新上限约 30fps），
  在高帧率下也不会一瞬间滑到目标位置。
- 未解锁的星球显示为暗色轮廓；一阶火箭能到达的天体在轨道模式下显示为绿色，其余为琥珀色禁止标记。
- 传送器已转为内部测试物品，只能用 `/give newgc:teleporter` 获取。

### 3. 传送系统

- 传送器（Teleporter）是本模组的核心工具，必须手持才能打开星图。
- 在星图中点击目标星球或右上角的“传送”按钮，即可传送到对应维度。

### 4. 重力系统

- 每颗星球拥有独立的重力倍率，通过 Mixin 在 `Entity.getGravity()` 统一缩放重力，并用同一倍率缩放坠落距离。
- 玩家的跳跃高度、下落速度、投掷物轨迹都会随重力变化。
- 物品实体的重力同样受影响，避免“同一个星球上人和物品重量不一致”的违和感。

### 5. 环境与天气

- 每颗星球拥有独立的天空渲染（自定义 `DimensionSpecialEffects`），例如水星的纯黑星空与高亮太阳。
- 部分星球有独特天气：金星下酸雨、火星有沙尘暴、木星卫星有极光。
- 环境音效与粒子效果按星球区分，例如金星地表有上升的酸雾粒子，火星有飘散的沙尘。

### 6. 氧气含量 HUD

- 氧气含量以 **HUD 形式显示在屏幕右下角**。
- HUD 采用条状指示器，直观显示当前剩余氧气百分比。
- 氧气耗尽后，玩家会持续受到窒息伤害，直到离开无氧环境或补充氧气。
- **右键使用氧气瓶**：手持已充能的氧气瓶，对着自己右键，即可补充氧气。
- **机器充氧**：与氧气抽取机交互，可自动将氧气瓶充满。

### 7. 金属、合金与机器

- 新增 6 种可开采金属：**铅、镍、铂、钛、铀、锌**，每种都包含原料、锭、粒、板和储存块，并在主世界通过独立的矿脉配置生成。
- 新增 4 种合金：**青铜**（铜 + 锡）、**钢**（铁 + 煤）、**琥珀金**（金 + 银）、**殷钢**（铁 + 镍），需要使用合金熔炉生产。
- **电力熔炉**：使用 FE 代替燃料，直接执行原版熔炉配方，速度约为普通熔炉的两倍。
- **合金熔炉**：双输入槽，按照配方熔炼合金；两个输入槽的顺序不影响匹配。
- **能量电池**：100 万 FE 储量的电网缓冲方块，可通过导线充放电。
- **导线**：黑色电缆配白色网格接头，物品栏图标只显示一根横向电线；方块按六个方向渲染独立线臂，只连接真正能输入/输出 FE 的方块。
- 所有新增机器都拥有独立的 GUI、能量条、进度条、NBT 持久化和掉落保护；能量网络通过 NeoForge `IEnergyStorage` 能力接入。
- **统一 GUI 风格**：所有机器界面使用同一套深蓝玻璃面板、冰蓝强调色、细边框和低对比度渐变；
  不再绘制“能量 / 输入 / 输出 / 进度”等文字标签或投料提示，只保留标题、槽位和可视化状态条，避免文字遮挡槽位。
- **状态提示与配方跳转**：进度条悬停只显示“查看配方”，点击可打开 JEI 对应机器的配方；能量和氧气条仍显示数值。
  安装 Jade 后准星指向机器即可查看加工/燃烧/氧气状态，不再重复显示能量条。JEI 与 Jade 均为可选兼容，不安装也能正常游玩。

### 8. 火箭与发射平台

- **发射平台**（`newgc:launch_pad`）：只有 1/4 格高的薄板，**必须摆成 2x2**（一次合成产出 4 块）才能放置火箭。
- **TBMK 工作台**（`newgc:rocket_assembler`）：3 格高、黑灰色、带加长机械臂的 3D 方块模型；
  打开后严格按照火箭外形排列零件：顶部对应等级的鼻锥、中间 2x4 重型合金板、底部对应等级的引擎，左右各两枚助推器。
  按“组装”按钮制作火箭；JEI 中拥有独立的“火箭组装”分类。
- **重型合金链**（全部从金属锭开始，不再使用板材合成合金）：
  - 合金炉：钢锭 + 镍锭 → 2 重型合金；
  - 合金炉：重型合金 + 铂锭 → 2 强化重型合金；
  - 合金炉：强化重型合金 + 钛锭 → 2 精英重型合金；
  - 压缩机：2 个对应合金锭 → 1 块对应等级的合金板。
- TBMK 工作台自身配方：2 机械外壳 + 2 钛板 + 2 殷钢板 + 1 金色电路核心 + 3 铁板。
- 生存路线：铜/锡 → 青铜；铁/煤 → 钢；铁/镍 → 殷钢；金/银 → 琥珀金；
  锌板参与机械外壳，铅板参与能量电池，逐级推进到钢/镍重型合金、铂强化、钛精英。
- **一阶火箭**（`newgc:rocket`）：16 段旋转面板拼出的圆柱 / 圆锥箭体，白灰纵向渐变、黑色级间环、
  橙色识别环，上部载人舱带四扇深蓝舷窗和正面舱门；最大直径约 1.1 格、高约 5.9 格。
- **二阶火箭**（`newgc:tier2_rocket`）：在相同箭体上增加两侧外置助推器、四片斜置尾翼和顶部通信天线，
  使用独立的冷蓝金属图集；上升时间 **150 秒**。
- **二阶部件链**：
  - 二阶鼻锥：钛板 + 强化重型合金板 + 钻石板；
  - 高级火箭引擎：钢板 + 铂板 + 钻石电路核心；
  - 在 TBMK 工作台用二阶鼻锥、8 块强化重型合金板、高级火箭引擎和 4 个助推器组装二阶火箭。
- **三阶火箭**（`newgc:tier3_rocket`）：白金 / 金色涂装，增加前后两组外置助推器、四片主翼和金色识别环；
  上升时间 **120 秒**。
- **三阶部件链**：
  - 三阶鼻锥：下界合金板 + 2 钛板 + 精英重型合金板 + 钻石板；
  - 三阶火箭引擎：4 钛板 + 4 铂板 + 下界电路核心；
  - 在 TBMK 工作台用三阶鼻锥、8 块精英重型合金板、三阶火箭引擎和 4 个助推器组装三阶火箭。
- 操作流程：
  1. 制作 TBMK 工作台，按火箭外形放入对应等级的鼻锥和引擎、8 块对应等级的合金板与 4 个助推器，点击“组装”；
  2. 摆放 2x2 发射平台，手持一阶、二阶或三阶火箭右键平台停靠；
  3. 右键火箭登乘（只能坐一人），进入后自动切换第三人称，并禁用创造模式飞行；
  4. **按空格发射**；也可以右键平台点火，或给平台通红石信号自动点火；
  5. **10 秒**点火倒计时中发动机提前冒烟，镜头震动随倒计时增强；随后平滑升空，
     一/二/三阶分别在约 **180 / 150 / 120 秒**后到达轨道高度，单次总爬升约 **4500 格**，
     飞行过程不参与方块碰撞；速度不会通过拉长时长来压低，等级越高上升越快；
     上升到约 160 格后天空逐渐变黑，约 480 格时完全进入星空，星星和附近天体图标会随高度淡入，
     不受白天或黑夜影响；高空太阳继续使用原版太阳贴图，不新增太阳纹理；
  6. 上升段屏幕最左侧显示竖直飞行进度条和玩家头像，头像从底部移动到顶部；
     到达**轨道**后自动打开星图选择目的地；星图图标、着色器和常用字形会在上升阶段分 tick 预加载，
     避免打开界面时集中读盘造成卡顿；
  7. 选中目标后火箭连同玩家一起跃迁到目标地表，**不再返回发射平台**；
  8. 按 **F** 打开火箭储物舱（9 格），发射时拆下的 4 块发射平台会自动存进这里；
  9. **左键点击火箭**可直接拆成掉落物（对应等级的火箭物品 + 储物舱全部内容）。
- **轨道航线规则（按“行星—卫星链”由内到外）**：
  - 行星/矮行星：一阶只能去最近卫星；二阶可去前两颗卫星；
  - 第一颗卫星：一阶回行星；二阶回行星并增加第二颗卫星；
  - 后续卫星：一阶去内侧相邻卫星；二阶增加外侧相邻卫星；
  - **三阶：当前行星的全部卫星 + 轨道距离最近的其他行星；从卫星出发时还会包含母行星，保证可以返回。**
    例如在木卫一出发，可前往木星、木卫二/三/四以及最近的谷神星。
  - 没有卫星且没有同恒星系相邻行星的天体（Proxima b）没有默认目的地。
- **发射前流浪检测**：如果当前天体和火箭等级没有任何可抵达目标，点火会被暂时拦下，并在聊天栏提示
  “发射后将进入太空漂流”；玩家必须在聊天框输入 `confirm`（60 秒内有效）才会强制点火。有目标时完全
  不提示，保持原发射流程；红石点火在无目标时会被阻止。
- **漂流模式**：关闭星图或等待 5 秒后，火箭连同玩家进入独立的 `newgc:space` 空维度。
  该维度只有虚空与星空，重力为 0；天空只绘制星点和**按实际 X/Z 位置计算的最近恒星图标**。
  太阳系显示太阳，Proxima b 显示 Proxima Centauri 红矮星，而不是固定显示地球或出发行星。
  火箭从轨道下方沿 Y 轴下降，**到达原版虚空判定高度 `minBuildHeight - 64` 后**每 20 tick 受到一次虚空伤害；
  生存模式的 HUD 显示 Y 坐标与原版虚空线，生命值仍由原版 HUD 显示。创造/旁观模式不会受到任何漂流伤害。
  在太空死亡后，玩家会回到火箭起飞的星球与发射平台坐标。轨道星图只有在这种情况下允许 ESC 关闭。
- 倒计时期间火箭仍立在 2x2 平台上，屏幕中央显示**红色大号倒计时数字**，镜头随倒计时增强水平、俯仰与翻滚抖动（火箭本体不动）；
  **真正起飞的瞬间**平台才会被拆除并收入储物舱，因此飞行途中不会再回到原平台；破坏平台上的火箭会退回物品。

## 多语言

- 机器 GUI、星图、飞行/磁场 HUD 等主要界面的用户可见文本已迁移到语言文件，不再在 GUI 代码中硬编码中文。
- 内置完整 **简体中文（zh_cn）** 和 **英语（en_us）**；另外提供 **日语、法语、德语、西班牙语、俄语、韩语** 的核心 UI 翻译，
  未翻译条目会自动回退到英语。
- 新增语言文件位于 `src/main/resources/assets/newgc/lang/`；可用 `python tools/generate_language_variants.py` 重新生成核心语言包。

## 项目结构

- `Planets/<天体>/`：每个行星/矮行星独立逻辑，包含自己的 `<Name>Sky` 天空类、距离表和邻居贴图。
- `Moons/<卫星>/`：每个卫星独立逻辑；卫星天空、效果和渲染全部位于 `Moons` 下，不再使用统一 `sky` 包。
- `gui/`、`network/`、`event/`：星图、传送、重生及通用事件。
- `item/material/`：金属、合金、板材和储存块的注册与创造模式物品栏。
- `block/entity/`、`menu/`、`client/gui/`：机器方块实体、容器菜单与客户端界面。
- `entity/`、`client/render/`：火箭实体、实体模型层与渲染器。
- `data/newgc/dimension`、`dimension_type`、`worldgen`：数据驱动的维度、群系和地形配置。
- `data/newgc/recipe`、`loot_table`：合成、熔炼、压缩、合金熔炼配方与方块掉落。
- `data/newgc/neoforge/biome_modifier`：主世界金属矿脉的 NeoForge 生物群系修改器。

## 注意事项

1. **世界兼容性**：模组仍处于 Demo 阶段，维度配置、方块 ID、地形生成参数可能随版本更新发生变动。**升级模组版本后，建议新建世界测试**，以免旧存档出现方块丢失、地形错位或维度加载失败。
2. **矿物独立**：本模组的矿物、锭、粒、块等物品与其它模组**不互通**。如果你同时安装了其他科技或矿物模组，它们的同类物品无法互相替换使用。
3. **客户端与服务端**：部分功能（如自定义天空、星图 GUI、按键绑定）属于**纯客户端逻辑**，但维度生成、方块注册等内容需要服务端同步。**多人游戏中，服务端与客户端的模组版本必须一致**。
4. **可选的 Stellar View 依赖**：如果你希望星空渲染更加丰富，可以额外安装 Stellar View。它不是必需依赖，但安装后能获得更细腻的星空效果。
5. **性能提示**：自定义天空渲染和维度生成会带来额外的渲染与计算开销。低配设备上如果出现卡顿，可以尝试降低渲染距离或关闭粒子效果。
6. **存档备份**：在切换模组版本或调整维度配置前，**务必备份存档**。地形生成参数的改动只对新生成的区块生效，旧区块无法回滚。

## 构建指南

如果你想从源码构建本模组，请按以下步骤操作。

### 环境要求

| 工具 | 版本 |
|---|---|
| JDK | 21 |
| Gradle | 随项目 Wrapper 自动下载 |
| IDE | IntelliJ IDEA（推荐）或 Eclipse |

### 构建步骤

1. **克隆仓库**

   ```bash
   git clone https://github.com/TairitsuTeK/New-Galaxy-MC-Mod
   ```

2. **导入项目**

   使用 IntelliJ IDEA 打开项目根目录，等待 Gradle 自动同步依赖。

3. **生成 IDE 运行配置**

   ```bash
   ./gradlew genIntellijRuns
   ```

   Windows 下使用：

   ```bash
   gradlew.bat genIntellijRuns
   ```

4. **运行客户端**

   ```bash
   ./gradlew runClient
   ```

   首次运行会自动下载 Minecraft、NeoForge 与相关依赖，耗时较长。

5. **构建发布 Jar**

   ```bash
   ./gradlew build
   ```

   构建完成后，产物位于：

   ```
   build/libs/newgc-1.0.7-alpha.jar
   ```

   `build/libs` 目录下通常会有两个文件，**带 `-sources` 后缀的是源码包，不带后缀的才是可发布的模组 Jar**。

### 常见构建问题

| 问题 | 原因 | 解决 |
|---|---|---|
| `Could not resolve` 依赖失败 | 网络无法访问 Maven 仓库 | 配置代理，或使用国内镜像 |
| `Unsupported class file major version` | JDK 版本不匹配 | 确认使用 JDK 21 |
| 运行时找不到 `neoforge.mods.toml` | 资源目录未正确配置 | 确认 `src/main/resources/META-INF/` 下文件存在 |
| Mixin 未生效 | `neoforge.mods.toml` 缺少 `[[mixins]]` 声明 | 在顶层添加 `[[mixins]] config = "newgc.mixins.json"` |
| 方块显示为紫黑方格 | 纹理文件缺失或路径错误 | 检查 `assets/newgc/textures/` 下对应文件 |

## 安装与依赖

- **Minecraft**: 1.21.1
- **NeoForge**: 21.1.1 或更高
- **Java**: 21
- **必需依赖**: 无
- **可选依赖**: [Stellar View](https://modrinth.com/mod/stellarview)（更丰富的星空渲染）、
  [JEI](https://modrinth.com/mod/jei)（配方查询与进度条跳转）、[Jade](https://modrinth.com/mod/jade)（机器状态 HUD）
